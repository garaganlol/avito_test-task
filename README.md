# Решение задачи ранжирования статей Авито

## Описание задачи
По запросу пользователя необходимо найти 10 наиболее релевантных статей из базы знаний Авито.  
Оценка производится по метрике **MAP@10**

---

## Использованные подходы и модели

- **Предобработка текста:**  
  Удаление HTML‑тегов, эмодзи, нормализация регистра и пробелов, замена буквы `ё` на букву `е`.

- **Chunking:**  
  Длинные статьи разбиваются на перекрывающиеся фрагменты (200 слов, overlap 30 слов), чтобы улучшить семантический поиск и уместить текст в лимит токенов эмбеддинг‑модели.

- **Лексический поиск (BM25):**  
  Реализован с помощью библиотеки `rank_bm25`. Токенизация включает лемматизацию (pymorphy3) и удаление стоп‑слов (nltk).

- **Семантический поиск (Dense):**  
  Используется предобученная мультиязычная модель **`intfloat/multilingual-e5-large`** (560M параметров). 
  
  Эмбеддинги вычисляются локально на GPU/CPU. Для запросов и документов применяются префиксы `query:` и `passage:` согласно рекомендациям авторов модели.

- **Индексация:**  
  Векторы чанков индексируются в FAISS (IndexFlatIP) для быстрого поиска по косинусному сходству.

- **Объединение результатов:**  
  Reciprocal Rank Fusion (RRF) с параметром k=5. Веса BM25 и dense равны.

- **Переранжирование:**  
  Добавлена TF‑IDF косинусная близость запроса к заголовку статьи. Оценки RRF и заголовка нормализуются (min‑max) и суммируются с весом 0.1 для заголовка.
